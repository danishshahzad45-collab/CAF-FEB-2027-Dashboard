Exam-focused weekly execution:
November: first-pass chapter learning; tick a chapter only after one independent question.
December: chapter-wise questions plus one timed sectional test per subject each week; clear every mistake in the log.
1–15 January: one 195-minute full mock per subject each week, then spend at least the same day reviewing lost marks and weak chapters.
16–31 January: prioritise FAR 1; keep Management Accounting and DSR active with timed mixed sets. Aim for repeated 65%+ in timed practice as an internal safety margin, not an ICAP prediction.
No plan can guarantee a 100% pass probability. The aim is to remove avoidable gaps and build exam-ready performance.

One-time setup guide

  1. Cloudflare account mein Workers & Pages → Create Worker → Deploy starter Worker.
  2. Worker ke code editor mein saath di hui CAF_AI_Marking_Worker.js file ka code paste karke Deploy karo.
  3. Worker → Settings → Variables and Secrets mein OPENAI_API_KEY ko Secret type mein add karo. API key browser ya GitHub mein kabhi paste mat karna.
  4. Wahin APP_ACCESS_TOKEN ko Secret type mein add karo. Ek strong random token khud generate karo; wohi dashboard ke connection box mein dalna.
  5. Worker ka workers.dev URL aur same app token upar save karke Test connection dabao.

Revision strategy

Revision 1 · 1 day laterRecall the rule/formula from memory and solve one short question.
Revision 2 · 7 days laterAttempt a fresh question without notes and correct the previous error.
Revision 3 · 21 days laterTimed mixed practice; update your weak-area list if any step is still slow.
The 1 / 7 / 21 intervals are spaced-repetition prompts, not a substitute for later full-syllabus revision.
